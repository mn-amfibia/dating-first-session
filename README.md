# Первая сессия в сервисе знакомств

Учебный интерактивный концепт для серьезных отношений. Не является продуктом Авито.

Сценарий: интересы → жизнь и привычки → цели и намерения → расстояние → необязательное окно с вопросом → предложение подписки.

На компьютере показаны карта экранов, телефон и обоснования. Кнопка «Только телефон» скрывает пояснения. На мобильном открывается сам сценарий. Состояния переключаются справа и предназначены для демонстрации: переключение подставляет тестовые ответы текущего шага.

## Открыть

Открыть `index.html` в браузере. Установка и сборка не нужны. Все ссылки на файлы относительные и работают в каталоге GitHub Pages.

## GitHub Pages

В репозитории: Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, /(root) → Save.

Ожидаемый адрес после успешной публикации: https://mn-amfibia.github.io/dating-first-session/

## Ограничения

- Ответы находятся только в памяти страницы и очищаются при обновлении. Сервер, аналитика и отправка ответов отсутствуют.
- Подписка, цена 399 ₽ и ее возможности демонстрационные. Платежи не выполняются.
- Экспертные CR являются допущениями. Общая модель 91,8% описывает доходимость до предложения, а не оплату.
- Будущие тематические подборки, напоминания и подбор по текстам не реализованы.
- Реестр гипотез: [HYPOTHESES.md](HYPOTHESES.md).
